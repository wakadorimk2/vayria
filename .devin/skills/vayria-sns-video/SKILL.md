# Vayria SNSデモ動画

SNS投稿用のVayria実演動画を制作する。手順の骨格・ffmpegレシピ・検証項目はグローバルスキル `sns-demo-video` に従い、このファイルはVayria固有の前提と確認項目を提供する。

## 収録対象と前提

- 収録先は原則として本番 `https://vayria.me/`。公開枠（日次・月次の利用回数）と有料生成費用を消費するため、収録前にテイク数と予算をユーザーへ明示して承認を取る。
- 見せ場の型: **カード交換 → 返答 → 生成で世界（背景・小物）が変わる → ヴェイリアが声・表情・動きで反応**。操作バーの「✨生成」をONにしないと生成は走らない。
- 「この生成機能は現在休止しています」が出た場合は本番収録を中止し、ステージング収録への切替またはOwnerへの有効化依頼を相談する。本番の採用設定を勝手に変更しない。
- Turnstile（cookieReady）とマイク・音声出力の動作を収録前に確認する。ページ表示だけでは録音・生成されない。
- 展示・運営画面（予算の内訳、管理操作、登録コード）は公開動画に映さない。

## 素材と出力先

- KV原素材: `docs/images/vayria-kv.png`（848×1200）、`docs/images/vayria-kv-poster.jpg`（1200×1694）。クレジットは「立ち絵：wakadori／キービジュアルデザイン：共同制作」。
- 制作物の保存先: `docs/sns/`（KV展開は `docs/sns/kv/`、動画・字幕は `docs/sns/assets/`）。
- 台本は `docs/sns/video-storyboard.md`、字幕は `docs/sns/assets/captions.ass`（スタイル付き正本。srtが必要な場合は派生として生成）を正本とする。
- 装飾レシピ（アクセント色・モーション・エンドカード・QA）はグローバルスキル `ffmpeg-usage` を参照する。
- mp4等の大きい素材のgitコミット可否は都度ユーザーに確認する。

## 公開文に使える確定事実

- 展示: 2026-09-23、浜松町館5F（GENAI EXPO系イベント）。ブース90×90cm。
- 公式サイト: `https://vayria.me/`。キャッチコピー「カードを選ぶ。会話が変わる。」。
- 未検証の性能・品質表現（速度・精度の数値、感嘆表現の断定）は文案・字幕に書かない。

## 収録前チェック

- [ ] `/api/session` が `enabled: true` を返し、公開枠に残がある
- [ ] 「✨生成」をONにして休止表示・エラーが出ない
- [ ] 画面に秘密情報・管理画面・個人情報が映らない配置になっている
- [ ] 収録方法（Game Bar/OBS推奨＝実音声あり）をユーザーと合意済み

# Vayria

Vayria（ヴェイリア）は、会話やカードの交換を通して、声・表情・動きで応えるAIキャラクターです。

言葉を交わすだけでなく、カードを一枚交換して、返答や反応の変化を楽しめます。

## Vayriaとの関わり方

### 話しかける

声や文字で話しかけると、Vayriaが音声と表情で応えます。
マイクを使わず、文字やカードからも関われます。

### カードを交換する

手札から一枚を選び、Vayriaの「脳内」のカードと交換します。
カードは、次の返答に影響します。

### 反応の変化を見る

返答の言葉だけでなく、声や表情、動きにも目を向けてみてください。
返答に作用したカードは画面で確認できます。

# wakadori

AI開発とイラスト制作をしています。
生成AIとキャラクター表現を組み合わせた、遊べる・会話できる体験を作っています。

AI Software Engineer & Illustrator. I create playful, conversational experiences with AI characters.

## Vayria（ヴェイリア）

**カードを選ぶ。会話が変わる。**

会話やカードの交換に、声・表情・動きで応えるAIキャラクターを制作中です。
立ち絵の制作と、会話や振る舞いを支えるソフトウェアの開発に取り組んでいます。

## 制作への関心

「AIだけでキャラクターが成立するのか」を、実際に作って確かめています。
返答の内容だけでなく、声・表情・動きや、話し始めるまでの間にも関心があります。

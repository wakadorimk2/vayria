# 公開Web版の字幕と音声入力表示

Liveの自分のSTTを表示しない。Vayriaの字幕には従来方式の`reply`表示を使う。
エラーと再生許可操作は字幕から独立して表示する。認識と再生制御は変更しない。

両方式の既存の入力音量から、48pxの円形表示を動かす。
音声入力の有無を示すもので、言葉を理解できたという表示ではない。
開始中は淡く静止する。無音時は円へ戻る。停止・エラー・方式変更中は非表示にする。
動きを減らす設定では輪郭を固定し、濃淡だけで音量を表す。

基準姿勢の頭部アンカーを投影し、顔の右側、左側、操作バー直上の順で空き領域を探す。
アンカーは画面サイズとカメラ配置に追従し、アニメーションには追従しない。
カード、字幕、案内、設定、操作バーを避ける。空き領域がない場合は重ねず非表示にする。

- 型検査、lint、stagingビルドが成功した。Viteの既存chunkサイズ警告は残る。
- ローカルUIで390×730と1024×768の画面を確認した。音量と字幕は合成値で、実マイクは使っていない。
- 自分のSTTの非表示、Vayria字幕の従来UI、顔の横の円、カード表示時の配置、設定パネルからの退避を確認した。

# 公開Web版の入力表示と字幕

## 動作

- 48pxの円を字幕の左側へ表示する。間隔は12px。画面左右に16pxを確保する。
- 円は既存のマイク入力状態と正規化済み音量を受け取る。新しい録音やSTT呼び出しは行わない。
- 入力音量を平滑化する。準備中は淡く静止する。停止時は非表示にする。動きを減らす設定では濃淡だけを変える。
- 字幕2行分の高さを予約する。字幕が消えても円の位置を維持する。
- 公開Web版の字幕は既存の会話処理の表示状態を使う。音声区間の再生終了から2秒後に消す。次の区間の開始でタイマーを解除する。
- ミュートなど音声を出さない返答は、表示後2秒で消す。本文自体や履歴は削除しない。
- 中断、セッション終了、参加者交代、画面非表示で消す。古いタイマーと、中断後に届く再生開始通知で再表示しない。
- ローカル・展示版の消去時間は変更しない。公開用の内部設定subtitleHoldMsだけを追加する。

## 分離範囲

mainを基準に切り出した。Liveの接続、Worker、課金、利用上限、iOSのLive用録音保持は含めない。
Live専用の字幕型、ページ分割、Canvas計測、定期的な字幕監視も含めない。
元のLiveブランチとDraft PR #113は保持する。このPRでは配信とマージを行わない。

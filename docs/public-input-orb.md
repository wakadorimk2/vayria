# 公開Web版の字幕と音声入力表示

Liveの自分のSTTは表示しない。エラーと再生許可操作は字幕から独立して表示する。
認識、口パク、再生終了の制御は変更しない。

## 字幕

Liveは現在の出力を逐次表示する。過去の発言を連結した末尾160文字の表示を廃止した。
実際のフォントと表示幅で最大2行に収める。あふれた場合は句読点の後の続き、または次のまとまりへ切り替える。
出力音声の活動と出力字幕の更新が両方2秒間止まると消す。字幕の時刻が2秒以上離れた場合も前の字幕を引き継がない。
これは表示用の無音判定であり、モデルの確定した発話終了イベントではない。
入力字幕は消去タイマーを延長しない。重複イベントと古い時刻の出力を除外する。
停止、方式変更、公開セッション終了、画面非表示で表示をリセットする。
従来方式の返答表示は維持し、既存TTSの再生状態を使って再生終了後2秒で消す。

## 円と配置

両方式の既存の入力音量から、48pxの円形表示を動かす。
音声入力の有無を示すもので、言葉を理解できたという表示ではない。
開始中は淡く静止する。無音時は円へ戻る。停止・エラー・方式変更中は非表示にする。
動きを減らす設定では輪郭を固定し、濃淡だけで音量を表す。

字幕の高さに、円を左、字幕を右へ並べる。間隔は12pxとする。
狭い画面では左右16pxを確保する。2行分の高さを予約し、字幕の有無で円を動かさない。
頭部アンカーと円専用の障害物探索を廃止した。設定パネル用のアバター範囲は維持する。

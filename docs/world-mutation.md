# 世界改変のローカル実験

カード交換をきっかけに、Vayriaとプレイヤーが同じ出来事に巻き込まれる機能です。初期カードは世界を生成しません。交換後の出来事は蓄積します。カードを抜いても世界は戻りません。

## 起動

```powershell
npm run dev:world:op
```

既存の1Password起動設定を使います。環境変数を自分で用意する場合は `npm run dev:world` を使います。`OPENAI_API_KEY` と既存の会話・TTS設定が必要です。通常起動では `VITE_WORLD_MUTATION_ENABLED=false` が既定値です。実験起動はこの値をtrueにし、アプリをlocalモードにします。public/exhibitionモードのAPIは世界改変を受け付けません。

最初に「水中」を脳内へ入れます。押し出された「鶏」を戻します。次に「巨大」を戻すと、世界の蓄積と対象の再利用を試せます。台詞と結末はLLMが決めます。

生成中も会話できます。カード由来の生成中は交換を止めます。「取り消す」は現在世界を残します。「Session Reset」はカード・会話・世界・観測・行動欲求を初期化します。生成回数は戻りません。「実験の状態」の「新しい実験」は生成枠も新しくします。

## 状態と責務

| 識別子 | 指す対象 | 更新する時点 |
| --- | --- | --- |
| WorldState | 画面へ反映済みの場所・環境・対象・雰囲気 | 画像読込後、発話の空き時間に確定 |
| MutationEvent | 解釈・本人の試み・変更案・副作用・次の興味 | 構造化応答の検証後 |
| WorldObservation | 完成背景の可視情報・不確実性・予定との差 | 画像解析後。世界の数量を上書きしない |
| WorldResult | イベントID・世代・版・変更案・画像・観測・時刻 | サーバー応答。表示まで保留 |
| WorldRuntime | ブラウザーの要求、保留、取消、表示確定 | カード・応答・リセット・毎秒の評価 |
| WorldMediaProvider | 構造化、画像生成、画像解析の外部処理 | サーバーが呼び出す |

サーバーは現在世界と脳内カードから変更案を作ります。全世界状態から画像プロンプトを作ります。ブラウザーは画像を読み込みます。進行中の発話が終わるまで旧背景を維持します。画像・世界・観測を同時に確定します。会話には表示済み情報と実際に配置する前景の要約を渡します。画像プロンプトは会話指示に流用しません。

画像は `gpt-image-2`、1536×1024、medium、PNG、1要求1枚です。構造化と画像解析は `gpt-5.6-luna` です。通常会話のモデルは変更しません。画像生成は150秒、構造化・解析はそれぞれ45秒で打ち切ります。自動再生成は行いません。画像解析だけが失敗した場合は画像を表示し、不確かな細部を断定しない会話へ切り替えます。

APIは `/api/world/experiments` と `/api/world/mutate` です。サーバーが実験IDを発行します。要求にはセッション世代、イベントID、表示中の版を含めます。古い応答・重複イベントを棄却します。画像生成前に要求数を記録します。失敗・取消後も数えます。構造化中の取消など、画像生成へ到達していない要求は画像枠を消費しません。

生成枠は実験あたり20回です。台帳はGit対象外の `.world-experiments` に保存します。プロセス再起動でも保持します。開発パネルの回数は最後の応答値です。ページ再読込や応答前の取消では表示値が遅れる場合があります。上限の判定にはサーバー台帳を使います。

## 表示と自発行動

生成背景、既存VRM、SVG前景を分離します。鶏・卵・羽・泡・火花の素材を同梱します。未知の対象は背景へ描きます。前景は最大6対象、各3枚で数量を代表表示します。世界内の数量そのものは保持します。手元素材はVRMの手の投影位置を参照します。胴体との前後関係と画面内の安全範囲を使います。握る・振る・抱える動作はありません。OSの動きを減らす設定では浮遊と粒子を停止します。

毎秒の行動欲求計算はLLMを呼びません。具体的な興味対象、好奇心、緊張、退屈、波、ノイズ、直前の行動ペナルティを使います。最低10秒休止し、ペナルティは30秒で減衰します。しきい値を超え、既存の会話実行枠が空いた場合だけ変更候補を問い合わせます。LLMは何もしない選択もできます。カード入力は自発行動の生成を取り消して優先します。

動画、衣装、身体変身、物理シミュレーション、公開サイト、展示運用は対象外です。将来の動画追加にはWorldMediaProviderとmediaの表示境界を拡張します。

## 接続失敗の原因調査（2026-09-09 08:30 JST）

## カードの鮮度と段階退場（2026-09-09）

`SceneProposal`はLLMによる情景の変更案です。`SceneElement`は基本対象、修飾、由来カード、元の対象データ、強化時刻、表示段階を保持します。基本対象と修飾は一つの表示枠を共有します。名前の対応は `docs/world-freshness-names.md` に記録しています。

鮮度は `0.5 ** (経過ミリ秒 / 180000) * (0.7 + 0.2 * カード支持 + 0.1 * 結び付き)` です。カード支持は、現在の脳内カードの時間減衰値の平均です。結び付きは、由来カードを共有する新しい情景がある場合に1とします。相互参照で減衰を止めないよう、一段だけ計算します。

0.65以上は詳細、0.35以上は簡略、0.15以上は遠景、それ未満は退場です。一回の世界更新で一段階進みます。簡略化では支持の弱い修飾から外します。大きさの修飾が外れた場合は通常サイズへ戻します。遠景では透過前景を外し、背景に小さな影として描きます。

表示枠は背景1、主役2、サブ生物1、小物1、演出2です。枠を超えた場合だけ段階を飛ばして退場できます。鮮度が同じ場合は、強化時刻が古い情景から退場します。同じ対象IDを複数の情景へ重複登録できません。最近の退場記録は12件、出来事の会話記憶は6件に制限します。

毎秒の計算は診断表示だけを更新します。減衰だけでLLMや画像生成を呼びません。画像が完成し、ブラウザーの読込と発話待ちが終了すると、背景・前景・表示段階・退場記録を同時確定します。画像用と画像解析用のデータには、過去の記憶や退場済み対象を含めません。自発行動の興味対象が退場した場合は、古い関心を解除します。

再試行ではカードの投入時刻を維持します。再投入は新しい時刻として記録します。単なる観測や変更のない自発提案では、強化時刻を更新しません。古い状態は由来不明として移行します。移行で生成回数を戻しません。

検証用の `scripts/world-freshness-playcheck.mjs` は明示的な実API試験です。`npm run test:world` の後に、ローカル実験サーバーのURLを引数として実行します。水中・鶏・巨大・きらきらの4回と、巨大の投入から210秒以上経過した後の秘密カード1回を生成します。各要求を20回上限に計数します。自動再試行はしません。生成画像と解析結果は `.world-experiments/freshness-*` に保存します。これはAPI検証であり、ブラウザー内の会話や音声の成功証拠ではありません。

# iPhone公開版の再生待ちと録音・再生切り替え

2026-09-08。対象はiPhone 15、Chrome、本体スピーカーで報告された初回発話待ちと、音声入力後の音のこもり。

## 修正

- 再生準備を世代で管理する。同じ準備は共有する。タイムアウト、中断、音源変更、dispose後の完了処理は新しい音源を消さない。
- AudioContextの再開は1秒で区切る。主発話で再開できない場合は既存の「音声を再開」を表示し、取得済みの音声を再開する。LLMとTTSを再要求しない。
- 公開版のiPhone/iPadだけ、再生前に録音トラックと録音用AudioContextを解放する。対応端末ではAudio Session APIも録音用と再生用に切り替える。
- 返答全体と個々の再生が録音停止を保持する。分割TTSの継ぎ目では録音を再開しない。短い音声反応も再生前に解放する。
- 返答終了後は、利用者がマイクオンを選び、セッションが有効で、タブが表示中の場合だけ自動再開する。再取得失敗時はエラー状態を保ち、マイクボタンから再開する。
- 手動オフや新しい発話の開始後に届いた古いマイク取得結果は破棄する。発話中の音声割り込みは提供しない。
- iPhone公開版の再生前にアプリ側の音量抑制も解除する。公開API、利用枠、local/exhibitionの録音方式は変更しない。

# 本人の領域と小物の段階表示

最新の方針：完成した小物を先に表示できる。背景の完成を必須条件にしない。既存のバストアップを維持し、小物は胸元を優先する。顔・字幕・カードと重なる場合だけ別の位置へ移す。手持ちモーションは対象外。

## 型と確定点

| 型 | 対象 | 役割 | 確定点 |
|---|---|---|---|
| WorldLayout | ビューポート、身体、顔、両手、操作領域 | 投影位置、配置判定、生成ガイドの共通入力 | 要求送信時のスナップショット |
| WorldPropAsset | 透過PNG、輪郭範囲、基準点、向き、表示幅、観測 | 検査済み素材 | 同梱時、または生成後の検査完了 |
| PendingWorldProp | 未到着対象のID、配置先、主役かどうか | 正体を断定しない気配 | 背景表示後。WorldStateには含めない |
| PropArrival | イベント、世代、背景版、対象、情景断片 | 遅着結果の照合 | 画像読込と発話待ちの完了後 |
| WorldStreamEvent | planned / background / prop / prop_error / error / done | ローカルAPIのNDJSONイベント | 各イベントの検証後 |

背景と小物は別の確定点を持つ。サーバーは計画の検証後に対象IDと版だけを通知し、小物は完成順に返す。先着した小物は画像読込と発話終了後に現在世界へ追加する。未完成の背景と副作用は追加しない。背景が後着した場合、先着小物を保持して合流する。先着小物の到着反応を繰り返さない。背景の失敗や取消でも表示済みの小物は保持する。リセットでは両方を消す。背景の読込後に発話が終わると背景を確定する。未到着対象は、現在世界と情景の参照から除外する。予定の行動や副作用も会話へ渡さない。小物の読込後に発話が終わると対象を追加する。到着だけでは情景の強化時刻を変更しない。

背景表示後に次のカードを受け付ける。次の交換、取消、リセットは未到着小物を無効化する。イベントID、セッション世代、背景版を照合する。画像生成に失敗した場合、直前の確定状態を維持する。小物だけの失敗は背景を維持する。

## 構図と前景

VRMの正規化ボーンをカメラへ投影する。身体と顔の範囲、左右の手元を取得する。顔の余白は初期値2.5%とする。カード、字幕、会話操作のDOM領域を配置禁止範囲とする。画像の輪郭範囲で重なりを判定する。小物は胸元の空いている場所を優先する。手元への配置は、手持ちモーションの実装後に検討する。配置できない場合は縮小する。それでも入らない場合は表示を見送る。

バストアップの既存カメラ設定を維持する。小物のために画角を引かない。開発パネルの「本人の領域を調整」で領域を表示する。身体と顔をドラッグできる。顔の余白と初期値復帰を操作できる。縦長・横長ごとにローカル保存する。

中央配置の `background-size: cover` の切り抜きを逆算し、1536×1024のガイド画像を作る。背景生成はガイドを `images/edits` の参照画像へ渡す。身体の背後は細部を抑える。ガイドの色や人物を描かないよう指示する。これは厳密な描画禁止マスクではない。前景の禁止範囲はアプリ側でも判定する。

主役の気配は背景表示と同時に始まる。通常の気配は300ms後に始まる。1200msを超えると泡状の輪郭を表示する。未知の対象の形状は仮表示へ使わない。生成完了の期限を300〜1200msに設定しない。動きを減らす設定では短いフェードだけを使用する。

## 生成とキャッシュ

背景は `gpt-image-2`、1536×1024、medium。未知の小物は同モデル、1024×1024、high、`background: transparent`、PNG、1枚。背景と小物に共通の絵柄と光の方向を指定する。画像要求ごとに150秒で打ち切る。画像解析と形式出力は `gpt-5.6-luna` を維持する。

未知の小物は1イベント1種類。背景と小物を並行生成する。生成前にサーバーが要求枠を永続化する。未キャッシュ小物と背景は各1回。同梱素材とキャッシュは追加計数しない。残り1回では背景を優先し、未知の小物を背景へ回す。失敗や取消で枠を戻さない。

PNGのアルファ、透過面積、輪郭の切れを検査する。画像認識でも対象と品質を検査する。検査失敗では表示もキャッシュも行わない。キャッシュキーは対象、形状の修飾、絵柄、向き。数量と表示倍率は含めない。ファイルは `.world-experiments/assets` に保存する。GET経路はSHA-256のPNG名だけを許可する。

送信後は送信日と確認対象だけを記録する。回答後は条件と回答日を記録する。

9月23日の展示で、iPadのブラウザーから公開Webアプリを利用する予定です。
作業用機器も使用する予定です。テザリングや独自の無線アクセスポイントは使用しません。
以下の回線条件をご教示いただけますでしょうか。

1. iPadを出展者向けWi-Fiへ直接接続できますか。認証方法、接続時間制限、再認証の条件はありますか。
2. 外部WebサイトへのHTTPS（TCP 443）通信に制限はありますか。音声を含む継続的なWebアプリ利用は可能ですか。
3. 参考確認として、同じ会場Wi-Fi内の端末間通信、mDNS、ローカルHTTPSは許可・対応していますか。現在の標準構成ではこれらへ依存しません。
4. 接続不良時の相談窓口と、運営が認める対処方法を教えてください。
5. 音声方式の候補として、ブラウザーから外部サービスへ接続するWebRTCを検討しています。WebRTCやUDP通信の制限、必要な事前申請はありますか。端末間のローカル通信とは別の確認です。

送信にはユーザーの明示指示を待ちます。登録コード、API key、会話本文、個人情報は文案へ追加しません。

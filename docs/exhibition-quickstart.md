# Vayria展示当日クイックスタート

9/10更新。現在の採用方針は、公開版と同じURL・ビルドの展示モードです。
配信とiPad実機の成功は、この手順の作成だけでは確認できません。
詳細は [公開版の展示モード](public-exhibition.md) を参照します。

会場は浜松町館5Fです。9/10の公式案内で確認しました。
展示登録先と検証パスは [比較開始票](exhibition-selection-20260910.md) で配信版と照合します。

## 起動前

1. 配信済みの版と展示モードの動作を確認します。未配信のローカル実装を当日のURLとして案内しません。
2. PCとiPad、充電器、音声機器を測定済みの構成にします。合計100W以内を確認します。
3. iPadを会場Wi-Fiへ接続します。PCも必要な会場Wi-Fiへ接続します。
4. 公開URLのHTTPS接続を確認します。認証画面がある場合は完了します。
5. 展示枠の期間、端末登録、残予算、停止状態を確認します。登録コードは保存・掲示しません。

会場ではWindows Mobile Hotspot、スマホのテザリング、モバイルルーターを代替回線として起動しません。
公開版はPCとの端末間通信やmDNSを必要としません。会場Wi-Fi経由のインターネット接続は必要です。
公式条件は [出展者案内](https://www.genai-expo.com/vol6/guide) で再確認します。

## 受付を始める前

1. iPadでカード操作から返答までを確認します。
2. マイク入力と実際のスピーカー音声を確認します。
3. 「体験を終える」を押します。古い字幕、入力、録音、再生が残らないことを確認します。
4. 次の参加者向けの案内を確認します。次の一往復を確認します。
5. 待機中に発話しないことを確認します。

iPadの縦横表示、タッチ、聴感は実機で確認します。模擬ブラウザー試験とは別に記録します。

## 障害からの復帰

| 症状 | 操作 | 再開条件 |
| --- | --- | --- |
| ページが開かない | 会場Wi-Fi、認証、HTTPS、配信状態を確認します | iPadで画面と一往復を確認します |
| 音声が出ない | ミュート、音量、出力先、マイク許可を確認します | 実際の入力とスピーカー出力を確認します |
| 交代が完了しない | 接続を確認し、終了要求を再試行します。必要ならページを再読込します | 交代完了後に新しい一往復を確認します |
| 期間・予算・端末登録で停止する | 運営パネルの状態を確認します | 承認された設定と有効な登録で一往復を確認します |

復旧のためにCookieを削除しません。Cookie削除は再登録を必要にします。
予算を独断で増額しません。未検証のローカル版へ切り替えません。
復旧できない場合は体験受付を停止します。

## 参考資料と終了

旧ローカル構成の有線LAN対応は、このPRには含めません。実装と実機検証を確認するまで代替構成にしません。
ローカル版の `exhibition:start:op` はHotspot前提の旧経路です。9/23の標準起動には使いません。
ローカルランチャー、STT、AivisSpeechの再起動やローカルexportを公開版の復旧手順に混在させません。
終了時は「体験を終える」を押し、録音と再生の停止を確認します。機材を照合して撤収します。
日程、比較、搬入物は [展示準備台帳](exhibition-readiness.md) を参照します。

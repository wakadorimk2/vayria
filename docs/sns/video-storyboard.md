# 実演動画 台本（15〜25秒）

見せ場: **カード交換 → 返答 → 生成で世界が変わる → ヴェイリアが反応**
収録先: 本番 https://vayria.me/（有料API・公開枠を消費。テイクは最小限）

## 収録前の準備

1. ブラウザーウィンドウを**縦長**にする（目安: 幅900〜1100px × 高さ1400px以上。Shorts向け9:16の主収録、X版はぼかしパッドで横長化）
2. https://vayria.me/ を開き、Turnstileとセッション開始を完了する
3. 操作バーの「✨生成」をONにし、休止表示・エラーが出ないことを確認する
   - 「この生成機能は現在休止しています」が出たら収録中止。staging代替か有効化依頼へ切替
4. 通知・他タブ・個人情報が映らないことを確認
5. 録画: **OBS（プロファイル「Vayria Promo」・シーン「Vayria収録」＝設定済み）**
   - ウィンドウキャプチャが `Vayria - Google Chrome`（chrome.exe）を指定済み、**ウィンドウ音声つき**＝ヴェイリアの声が入る
   - **Chromeで** https://vayria.me/ を開き、縦長（幅640px前後×高さ1300px前後、キャンバス636×1304に合わせる）にする。Edgeではキャプチャされない
   - OBSプレビューに画面が映ることを確認 → **Ctrl+Shift+Alt+F8**で録画開始 → 実演 → **Ctrl+Shift+Alt+F9**で停止
   - 出力: `C:\Users\wakad\Videos\` にmp4（NVENC）で保存される

## カット構成（目安20秒）

| 秒 | 操作・セリフ | 見える変化 | 成功条件 | 字幕 |
| --- | --- | --- | --- | --- |
| 0〜3 | 体験画面を表示したまま待つ | Vayriaの待機モーション | 画面が安定して映る | 「カードを選ぶ。会話が変わる。」 |
| 3〜7 | 「カードで遊ぶ」→手札から1枚選び、脳内スロットへ投入 | カードが移動し選択状態になる | 投入の受理が分かる | 「カードを1枚、渡してみる」 |
| 7〜10 | **明示依頼を言う**（セリフ例は下記） | 入力が送信される | 依頼が画面に出る | 「世界が変わって――」 |
| 10〜17 | 返答と生成を待つ（※待ちは編集でカット可） | 通知→生成された小物・背景が世界に現れる | 世界の変化が判別できる | （同上） |
| 17〜22 | そのまま観察 | Vayriaの返答音声・画面内字幕・表情変化 | 発話字幕と表情の変化が映る | 「ヴェイリアが応える」 |
| 22〜25 | 終了カット | 落ち着いた画面 | サイト名が読める | 「9月23日 展示 / vayria.me」 |

## セリフ例（7〜10秒の明示依頼）

生成は「出して・作って・召喚して」のような**現在の明示依頼**で発火する。引用・否定・条件付きの言い方では発火しない。
音声なら「マイクで話す」→発話、文字なら「文字で話す」→入力して送信。

| セリフ | 備考 |
| --- | --- |
| 「鶏を出してみて」 | 既存素材優先で最速。確実に世界が変わる |
| 「猫を召喚して」「魚を出して」 | モノ名の明示依頼。新規生成の見せ場 |
| 「カニを呼んで」 | 同上 |

1テイクで「カード投入→依頼→生成→返答」まで流す。返答が依頼の復唱になった場合は撮り直し候補。

## 派手テイク用レシピ（第4テイク以降）

効果カードの組み合わせで見た目を派手にする。アイテムのスプライトサイズは `min(168, max(72, ウィンドウ狭辺×18%)) × 個別スケール`（`src/sharedWorld/spriteLayout.ts`）なので、ウィンドウを広げても相対比率は不変。**派手さは個数とエフェクトで作る**。

| 手順 | 投入するカード/入力 | 起きること |
| --- | --- | --- |
| 1 | 「無重力」or「宇宙」 | 部屋がzero-g化、全アイテム浮遊（最も絵になる） |
| 2 | 「増える」 | 対象の個数が倍加（worldIntent経由、上限1000） |
| 3 | 「踊る」「弾力」「発光」「金色」「巨大」 | 全アイテムが踊る/跳ねる/発光/1.5倍 |
| 4 | モノ系を連続投入（猫・きのこ・カニ・ロボット等） | 1投入ごとに+3体（上限24）、閾値超えで「群れ」発生 |
| 5 | 文字入力「クラゲを呼んで」等 | 新規生成＝チェストに大きく配置 |

- 環境系（宇宙・水中・砂漠等）は背景生成が無効のため背景は変わらないが、物理モード（無重力・水中）は有効
- 音声入力は滞留する既知問題があるため文字入力のみ使う
- 全効果を1テイクに集約し、公開枠・生成枠の消費を抑える

## 収録の学び（2026-09-16 第1・第2テイク）

- **背景・修飾系カード（雪・きらきら等）は使わない**: 背景生成 `VISUAL_BACKGROUND_ENABLED` は無効の仕様のため、投入・返答は成功しても見た目が変わらなかった
- **モノ系カード（猫・魚・鶏など）を選ぶ**: 投入だけで既存/簡略素材の3体が物理落下し、生成画像へ置き換わる。世界変化が確実に映る
- 「〜を作るね、どう扱おう？」のように意図が確定しない返答の場合は、依頼を短く明示的に言い直す
- **音声入力は避ける（共有会話モードで滞留を確認）**: 共有会話では音声発話が部屋スロットの許可（`slot.status==='granted'`）待ちになり、最大120秒ブロックされる（`src/sharedWorld/voice.ts`）。待機中はbusyで後続発話も処理されず、マイクONのまま進行が止まって見える。彼女の返答・音声が完全に終わる前に話すと特に起きやすい
- **推奨の入力**: ①モノ系カード投入のみ（第1テイクで投入→発話は動作済み）、または ②「文字で話す」→「猫を出して」等を入力
- 参考録画: `2026-09-16 20-37-23.mp4`（120秒、雪カード＝背景系で世界変化なし）、`2026-09-16 20-46-07.mp4`（24秒、音声入力がスロット待ちで滞留）— いずれも `C:\Users\wakad\Videos\`、本編には不使用

## 収録メモ

- 生成の待機（判断→表示）は実測で数秒〜最大30秒。待ちが長い場合は編集で間を詰め、総尺15〜25秒に収める
- ヴェイリアの発話内容は収録時に確定するため、字幕タイミングはテイク後に `captions.srt` を合わせ直す
- 映り込みNG: 展示運営パネルの予算詳細、管理URL、登録コード、他の個人情報
- 失敗テイクは破棄し、公開枠の残数を確認してから再収録する

## 編集手順（収録後に実施）

実施済み（2026-09-16 第4テイク・派手版）: `2026-09-16 21-50-42.mp4` の 123.0〜146.3秒（23.3秒）+ 1.5秒エンドカード = 24.3秒。
内容: 「かわいい」投入 → クラゲがスロット入り＆出現・浮遊 → 「きらきら」「浮く」「豪華」投入 → 剣・ロボット・猫・みかん・クラゲで高密度の世界 → 返答「今日は花が多いね。みんなのところはどう？」（音声142.7〜145.7秒で完結）
字幕の正本は `assets/captions.ass`（BIZ UDPGothic Bold・`\fad`フェード・`\t`スケールポップイン・半透明ボックス・キーワードにピンクアクセント `&HC3A7F4`）。`captions.srt` は派生として同期済み。
縦長1080×1920マスター1本を生成し、Shorts/Xで共用（Xは縦長対応のため）。エンドカードは `kv/vayria-kv-shorts.jpg` をxfadeで接続。

```powershell
# Step 1: 本編（ぼかしパッド・彩度微増・ビネット・冒頭フェード・loudnorm）
ffmpeg -ss 19.5 -to 42.8 -i raw.mp4 -filter_complex "[0:v]split[a][b];[a]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,gblur=sigma=30[bg];[b]scale=1080:1920:force_original_aspect_ratio=decrease[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2,eq=saturation=1.08,vignette=PI/6,fade=t=in:st=0:d=0.4[v];[0:a]loudnorm,afade=t=in:st=0:d=0.3,afade=t=out:st=22.9:d=0.4,aformat=sample_rates=48000:channel_layouts=stereo[a]" -map "[v]" -map "[a]" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -c:a aac -b:a 192k main_comp.mp4

# Step 2: エンドカードをxfade接続 + ass字幕焼き付け（縦長マスター）
ffmpeg -i main_comp.mp4 -loop 1 -t 1.5 -i docs/sns/kv/vayria-kv-shorts.jpg -f lavfi -t 1.0 -i anullsrc=r=48000:cl=stereo -filter_complex "[1:v]scale=1080:1920,fps=30,format=yuv420p[card];[0:v]fps=30[v0];[v0][card]xfade=transition=fade:duration=0.5:offset=22.8[vx];[2:a]aformat=sample_rates=48000:channel_layouts=stereo[si];[0:a][si]concat=n=2:v=0:a=1[ax];[vx]ass=docs/sns/assets/captions.ass[vout]" -map "[vout]" -map "[ax]" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart docs/sns/assets/vayria-demo-shorts.mp4

# X版はマスターのコピー（同一縦長ファイル）
cp docs/sns/assets/vayria-demo-shorts.mp4 docs/sns/assets/vayria-demo-x.mp4
```

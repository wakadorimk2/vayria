# 共有世界の輪郭と介入コメント

## 表示

カードパネルはカードアイコンとEscで閉じる。独立した閉じるボタンと空の受付帯は表示しない。前景から背景・痕跡へ移った小物も描画しない。保存データ、減衰、背景画像、特別演出は維持する。

投入コメントは参加者名とカード名を表示する。右から250msで入り、4秒で消える。最大3件。同一参加者名・カードの1秒以内の投入を集約する。初回取得・再接続・世代変更で過去の履歴を再生しない。顔と操作領域を避け、空きがない場合は表示を抑制する。

## 衝突形状

透過画像を長辺256pxまで縮小して解析する。アルファ32以上を対象にする。微小な孤立点を除外する。最大16本の水平帯ごとに凸包を作り、Matter.jsの複合ボディにする。内部の穴と帯より細い凹みは再現しない。輪郭を正方形の表示座標へ正規化し、画像と重心のずれを補正する。

キャッシュは素材URL単位で最大128件。解析前と失敗時は円を使用する。素材置換では表示原点、角度、速度、数量を維持する。解析は画像取得後に端末内で行う。外部画像APIは追加で呼ばない。

## 起動と体験

`npm run public:build`で公開版とWorkerをビルドする。既存の公開版起動・配信手順を使う。
本変更では本番・stagingへ配信していない。
公開版の「設定 → 会話設定 → 三者会話（展示用・試作）」を選ぶ。
実行モードはpublicのまま。既存のCookie、セッション、Turnstile、利用制限、TTSチケットを使う。
再読み込み時は通常へ戻る。会話設定は権限を増やさない。
展示端末の登録と専用予算はmainの運営機能を使う。未登録なら一般公開の利用枠を使う。
参加者交代では会話設定と音声方式を保持する。音声比較のファイルは破棄する。

顔を主役にする。カードと文字入力は必要なときに開く。
文字入力の「場の会話」は、共用マイクと同じ文脈判断へ送る。「Vayriaへ」は明示的な直接入力である。
「Vayriaに振る」は直前の会話への参加を促す。名前のない発話も、音声・場の会話経路では判断対象にする。
出展者と参加者の話者IDは推測しない。履歴には人の発話と実際に届けたVayriaの発話を残す。

参加判断は既存のvoice応答契約を使う。LLMは話す・聞く・非言語反応を選ぶ。
前回試作の名前と8秒の返答規則は、公開版展示の入口では使わない。従来のローカル展示経路には残る。
最後の音声活動から900 msの静けさと、進行中の文字起こしの完了を待つ。
900 msは初期値であり、展示の実測値ではない。
人が再び話し始めたら未再生の判断を失効させる。消費した会話を無音中に繰り返し判断しない。
公開APIの同一セッション同時実行制限を守るため、生成と文字起こしの送信を直列にする。
三者会話では先行音声とストリーミング音声を止め、判断完了後に再生する。待ち時間への影響は実測が必要。

参加者交代と会話設定変更では、処理中の生成、音声、文字起こし、未送信入力を破棄する。
会話、カード、来場状態を初期化する。
登録端末の交代は「体験を終える」を使う。既存APIで世代を更新し、失敗時は再試行する。
未登録の試作では設定内の「次の参加者へ」でローカル状態だけを初期化する。
交代後はマイクを自動再開しない。展示予算・一般利用枠を戻さない。
会話設定と音声方式の変更では公開セッションを保持し、以前有効だったマイクの再開を試みる。
失敗時はマイク操作から再試行する。

## 音声比較

指定対象はiPad Pro 12.9インチ第5世代の内蔵マイク・スピーカー。
公開版の通常設定は、iOSで録音を解放して再生する現在の方式を維持する。
展示設定では「録音を停止して再生」「同時録音・再生／auto」「同時録音・再生／play-and-record」を選べる。
Audio Session API非対応時は設定適用を保証しない。診断はunsupportedと表示する。

「音声比較と診断」で8 MB以内の短い音声ファイルを選ぶ。同じファイルを4条件で再生する。
ファイルはメモリー内だけで保持し、同じアプリの再生処理に渡す。外部送信しない。
比較中は文字起こしを抑制する。マイクあり比較の開始には通常の公開セッションとマイク許可を使う。
「マイクなしで比較再生」はマイクを停止する。後続の比較で必要な場合に再取得する。

| 条件 | 実機結果 |
|---|---|
| マイクなし | 未実施 |
| 録音停止・再取得 | 未実施 |
| 録音維持・auto | 未実施 |
| 録音維持・play-and-record | 未実施 |

診断は要求方式、実際の音声設定、AudioContext、音量抑制、録音解放・取得時刻、待機数を示す。
最大40件のメモリー内記録だけを保持する。会話本文、生音声、デバイスIDを診断へ保存しない。

同時録音では進行中を含む最大4件の文字起こしを順番に処理する。
会話判断前のテキストも最大4発話・合計1000文字とする。上限では録音を停止し再開案内を出す。
エコーキャンセルを要求する。音量だけで割り込みを確定しない。
候補で音量を下げ、確定テキストが再生文の一部なら自声候補として見送り、それ以外で中断する。
これは保守的な文字列照合である。短い自声、ASR誤り、人がVayriaの言葉を引用する場合を完全には識別できない。
同時録音の成功、声のこもりの解消、誤割り込みの抑制は実機未確認である。
